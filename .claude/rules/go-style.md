# Go style

> The Go standards live in **`pkg/CLAUDE.md`**, which auto-loads for everything
> under `pkg/`. This file exists only so the handful of Go files outside it —
> `main.go`, `main_server.go`, `assets.go`, `cmd/bug-finder/`, `cmd/seed-dev/`,
> `spike/onnx/` — get the same rules, since a nested `CLAUDE.md` cannot reach
> them.
>
> **Nothing is stated here.** A rule written in two places drifts in one of
> them, which is the failure this whole restructure exists to end. If you find
> yourself adding content below this line, put it in `pkg/CLAUDE.md` instead.
