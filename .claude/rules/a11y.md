# Accessibility (frontend)

Loads when you touch the app shell, a component, styles, or a test spec — the
places where accessibility decisions actually get made. General frontend context
is in `frontend/CLAUDE.md`.

## Spec setup

- **Force `prefers-reduced-motion: reduce` in a11y specs** via
  `page.emulateMedia()` in `beforeEach`. Without it, axe-core's color-contrast
  check samples mid-animation alpha (`view-fade-in` ramps opacity 0→1 over 360ms)
  and reports legible colors as failing. `use.reducedMotion: 'reduce'` in
  `playwright.config.ts` does NOT work as of Playwright 1.60 — the project-level
  `use: { ...devices['Desktop Chrome'] }` shadows it. `page.emulateMedia()` in
  `beforeEach` is the only reliable lever.

## Contrast

- **WCAG AA on every surface.** Compute contrast for new text/accent colors
  against ALL of `--surface-2`, `--surface-3`, `--bg` — small UI text (≤14px
  non-bold) needs 4.5:1 on every surface. The ~0.4% luminance variance between
  surfaces is enough to flip borderline colors. OW Dark grounds on `#2a2a2a` (not
  the literal brand-gray `#4A4A4A`) because the latter caps the OW orange
  `#fa9c1b` at ~3.8:1 on the brightest surface — sub-AA. `--brand-gray` stays
  `#4A4A4A` as a *structural plate* token (brandmark tile, dossier surfaces) so
  the OW identity reads. Day's `--accent` is the same OW orange; text-on-fill
  uses the `--primary-text-on-accent` token. OW Dark's `--loss` was bumped to a
  lighter pink and `--loss-soft` opacity dropped to 8% so loss text on
  double-tinted bgs (a danger card containing a danger chip) clears AA. (Exact
  hex values live as CSS custom properties in `app.css` — treat the tokens, not
  these prose values, as canonical.)

## Patterns to mirror, not reinvent

- **Modal dialogs**: focus trap + Escape + return-focus + background `inert`
  wired inline in App.vue (`showUnsupportedModal` + `onModalKeydown` + the
  `watch(showUnsupportedModal, ...)`). For *stacked* modals, see the
  capture-phase Esc gotcha in `frontend/CLAUDE.md`.
- **Tablist**: Arrow/Home/End automatic-activation via `useTabKeyboardNav`,
  cycling `TAB_ORDER` (the masthead is a `v-for` over the same list via `TABS`,
  so a tab cannot exist in one and not the other). Every view is a tab —
  `ViewId = TabId`; the film room renders inside the Reviews tab.
- **Skip-link**: `.skip-link` → `<main id="main-content" tabindex="-1">` with a
  `focusMain` handler for browsers that don't move focus on hash navigation.
- **Reduced-motion**: a global `@media (prefers-reduced-motion: reduce)` block at
  the top of App.vue's styles collapses every animation/transition to 0.01ms.
- Tests for each live in `App.test.ts`.
