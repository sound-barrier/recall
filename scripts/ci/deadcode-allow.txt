# App.ReParseAll: the desktop "Re-parse all" button drives this
# synchronous method over Wails IPC. Server mode's POST
# /parses?scope=all routes through the async StartParse(true) instead
# (a background job that returns 202 up-front), so the serveronly
# build never calls ReParseAll directly.
#
# App.ParseScreenshots joined it when the coaching write gate landed: the
# gate sits on the user-initiated entry points, so the file watcher — which
# is deliberately exempt (it only ever ingests THIS user's screenshots into
# THIS user's store) — now calls the internal parseSync directly rather than
# routing through the gated method. ParseScreenshots is therefore the
# desktop "Parse now" IPC entry only, and the serveronly build never calls
# it. This comment previously claimed the watcher kept it reachable; that
# stopped being true, which is why the gate caught it.
App\.ReParseAll
App\.ParseScreenshots
