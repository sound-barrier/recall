# Per-directory file budgets, asserted by scripts/ci/check-package-size.sh.
#
# ONE ENTRY PER LINE:
#
#     <repo-relative dir>   <budget>|exempt   [<waiver>]
#
# Every entry MUST carry a `#` comment block on the line(s) DIRECTLY above it
# saying why the number is that number — the same convention the byte budgets
# in check-bundle-size.sh follow, and the script rejects an entry without one.
# A blank line between the comment and the entry breaks the pairing.
#
# WHAT IS COUNTED lives in the script's header, not here. Short version:
# non-test .go files in a Go package; every tracked file in a frontend
# directory, except *.test.ts under frontend/src (a unit-test sibling is a
# projection of the file beside it); per-directory, never recursive.
#
# A DIRECTORY NOT LISTED gets DEFAULT_MAX_FILES, which lives in the script and
# is deliberately NOT restated here — a number spelled in two places is the
# drift that already bit this repo three ways with the coverage floors. Run
# `task package-size-audit` to see it applied. That default is the standing
# decision — "no grouping grows past it without a written reason" — not an
# escape hatch. Registration is earned by size, which is why this file is short
# and every line in it is load-bearing. Deleting an entry does not dodge the
# gate: an over-budget directory falls back to the default and fails harder.
#
# BUDGETS ARE ZERO-HEADROOM ON PURPOSE, and this is the one place this file
# deliberately diverges from check-bundle-size.sh. Byte budgets need slack
# because bytes move on every edit. A FILE COUNT only moves when someone
# deliberately creates a file — which is exactly the moment worth a thought. So
# a budget is the count on the day it was registered, and the next file trips
# the gate. That trip is cheap to answer and it is the entire mechanism.
#
# THE THIRD COLUMN IS A WAIVER: a temporary allowance ABOVE the budget for a
# directory that is over target today with a split owed. The budget column
# carries the TARGET, so this file records intent rather than ratifying sprawl.
# The script warns for every waived directory, fails if the count exceeds the
# waiver (debt may shrink or hold, never grow), and fails when the count reaches
# the budget so the waiver is DELETED rather than left to rot.
#
# Bumping a budget: change the number, rewrite the comment above it, and append
# a row to scripts/ci/package-size-budget-history.md.
